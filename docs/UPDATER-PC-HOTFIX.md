# 기존 BAT에서 PC 화면 크래시 수정 받기

`Cobbleverse-Update-Launcher.bat`는 `main`의 Launcher를 받습니다. BAT 자체를 다시 전달하지 않아도 Launcher 변경을 main에 반영하면 새 경로를 사용합니다.

Launcher가 프로필의 Cobblemon 버전을 확인합니다.

- 1.8.2 이상, 1.9 미만: 통합 프로필용 PC hotfix 경로를 사용합니다. 이전 스냅샷의 증분 패치 체인은 적용하지 않습니다.
- 1.8.2 미만: 기존 Bootstrap 및 증분 패치 체인을 그대로 사용합니다.
- 중복 Cobblemon, 해석할 수 없는 버전 또는 1.9 이상: 변경하지 않고 중단합니다.

PC hotfix는 More Cobblemon Tweaks가 설치되어 있고 1.3.6 미만일 때만 공식 Modrinth CDN에서 1.3.6을 받습니다. 약 135KB이며, 고정된 공식 SHA-512 및 모드 ID·버전을 확인한 뒤 교체합니다. 더 최신 버전은 내리지 않습니다. 게임 실행 중에는 중단하고, 기존 JAR은 프로필의 `.cobbleverse-pcfix-...` 폴더에 백업합니다. 단축키, 그래픽, 월드, 기존 증분 업데이트 상태는 변경하지 않습니다.

이는 PC 정보창을 닫을 때 발생하는 NoSuchMethodError 수정용입니다. 이전에 별도로 만든 키 설정·리소스 패치와 전체 통합 모드팩을 자동 설치하는 기능은 이번 변경에 포함하지 않습니다. 탑승 좌석 데이터팩 수정은 서버에서 적용합니다.

프로필 검색은 새 통합 테스트 프로필 이름과 버전이 다른 pack guard 파일도 인식합니다. 정확히 이름이 일치하는 통합 프로필을 우선 선택하고, 모호하면 기존 방식대로 경로 입력을 요청합니다.

## 검증

Windows PowerShell에서 다음을 확인했습니다. 실행 중인 게임 조회는 격리된 테스트 프로필에서만 모의했습니다.

- 실제 통합 프로필의 1.8.3 버전 탐지(읽기 전용).
- 1.8.3 + Tweaks 1.3.3 임시 프로필: 공식 다운로드·해시 검증·교체·백업.
- 1.8.0 임시 프로필: 레거시 경로 코드 20, 설치 파일 유지.
- 게임 실행 상태 모의: 변경 거부.
- 두 번째 실행: 재설치 및 추가 백업 없음.
- 개인 설정 보존 및 Launcher 구문 검사.

서버에서의 실제 게임 플레이 또는 PC 화면 조작 검증은 하지 않았습니다. 테스트 결과는 `integration/pc-updater-verification.json`에 기록합니다.
