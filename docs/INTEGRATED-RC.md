# COBBLEVERSE Integrated 2026.10.25-rc1

Minecraft 1.21.1 / Fabric 0.18.4 / Cobblemon 정식 1.8.3을 사용하는 로컬 통합 시험판입니다. 클라이언트 158개, 서버 121개 모드를 포함합니다.

## 서버 실행

1. 새 `Server` 폴더를 서버용으로 사용합니다. 기존 서버나 월드에 덮어쓰지 않습니다.
2. Java 21을 설치하고 `java -version`으로 버전을 확인합니다.
3. Minecraft EULA를 읽고 동의하는 경우 `eula.txt`의 `eula=false`를 `eula=true`로 바꿉니다.
4. `start-server.bat`을 실행합니다. 기본 최대 메모리는 8GB입니다. 첫 실행은 필요한 서버 파일을 내려받으므로 인터넷 연결이 필요합니다.
5. 같은 PC에서는 `localhost`, 같은 공유기의 다른 PC에서는 서버 PC의 내부 IP로 접속합니다. 외부 접속에는 공유기 TCP 25565 포트 전달 및 Windows 방화벽 허용이 별도로 필요합니다. 이 작업에서는 네트워크 설정을 변경하지 않았습니다.
6. 종료할 때 서버 콘솔에서 `stop`을 입력합니다.

기본 포트는 25565입니다. 기존 서버가 같은 포트를 사용하고 있다면 두 서버를 동시에 실행하지 말고 새 서버의 `server.properties`에서 포트를 바꾸세요. 기존 서버는 이번 작업에서 실행하거나 중지하지 않았습니다.

## 플레이어 설치

Modrinth App의 파일 가져오기에서 `Player/COBBLEVERSE-Integrated-2026.10.25-rc1.mrpack`을 선택하고 **새 프로필**로 설치합니다. 첫 설치에는 공식 모드 다운로드를 위한 인터넷 연결이 필요합니다. 실행 후 멀티플레이에 서버 주소를 추가하세요. 이전 프로필에 파일을 덮어쓰는 방식은 사용하지 않습니다.

기존 월드, 계정, 로그, 테스트용 데이터팩은 배포본에 포함하지 않았습니다. 새 월드 사용을 권장합니다. 기존 월드를 옮기려면 별도 백업 후 호환성 검증이 필요합니다.

## 정리한 기본 단축키

C: 코블몬 정보/스타터, R: 포켓몬 꺼내기, 위·아래 화살표: 파티 선택, B: 배낭, P: 원격 PC, M: 전체 지도, Z: 확대, F6/F7: 레이드 수락/거절, 숫자 1 왼쪽의 백틱: 퀘스트북입니다. 퀘스트 화면 중앙 맞추기는 Home입니다.

일반 조작과 겹치는 FTB 화면 편집 단축키, F6 초해상도 설정, K 셰이더 전환, 마우스 가운데 버튼의 두 정렬 단축키는 미지정으로 정리했습니다. 정렬은 각 보관함 화면의 정렬 버튼을 사용하세요. 기능을 다시 키에 배정하려면 조작 설정에서 비어 있는 키를 선택할 수 있습니다. 미지정 항목은 같은 키로 취급하지 않습니다.

## GitHub 배포

저장소: https://github.com/ApriL2-7/COBBLEVERSE-1.8-Snapshot-Custom

기존 업데이트 도구는 `mods/`, `resourcepacks/`만 처리합니다. 이번 통합본의 FTB 퀘스트 설정과 데이터팩을 모두 설치하려면 전체 `.mrpack`을 별도 GitHub Release 첨부 파일로 배포해야 합니다. 기존 패치 인덱스에는 연결하지 않습니다.

Git에는 도구 소스, 변경 기록, 해시 목록만 보관합니다. 제삼자 JAR 및 리소스팩은 Git 커밋에 넣지 않습니다. 공개 Release 업로드는 아직 하지 않았습니다. 포함된 수정 모드와 퀘스트북/리소스팩의 재배포 허용 범위를 확인한 후 공개해야 합니다.

## 확인 범위와 남은 문제

클라이언트 실행, 새 월드 생성, 스타터 지급, 퀘스트북 화면, 배틀타워 팀 등록 및 실제 NPC 전투 시작까지 확인했습니다. 이후 사용자가 실행한 전용 서버의 정상 기동 및 외부 플레이어 접속도 로그에서 확인했습니다. 배틀타워 승리·연승·보상, PC 정렬·잠금 유지, 모든 퀘스트 보상, 배포 파일의 새 프로필 가져오기는 검증하지 않았습니다. 리소스 및 패킷 수정 이후 재실행 검증은 아직 하지 않았습니다.

퀘스트북에 현재 모드에 없는 `lumymon:zeraorite`, `lumymon:zygardite`가 남아 있습니다. NPC 포켓몬의 도감 처리 경고와 일부 기존 모델 경고도 남아 있습니다. 상세 목록은 `KNOWN-ISSUES.json`을 확인하세요.

한국어 JSON과 일부 모델·텍스처 참조, 리소스팩 설정 오류에 대한 수정 범위는 `docs/RESOURCE-FIXES-2026-10-25.md`에 기록했습니다.

`tools/package-integrated.py`는 현재 로컬 통합 프로필에서 배포 파일을 생성합니다. 원본부터 모든 호환성 패치를 자동 적용하는 설치 도구는 아닙니다.
